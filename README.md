**谱间 · 简谱编辑器**

旋律和歌词的本地编辑工作台，使用 JavaScript ES Modules + SVG，无前端依赖。

[歌声提取：实现、架构及商业许可](doc/歌声提取与旋律记谱-架构及商业许可.md)。Demucs 代码为 MIT，但当前官方预训练权重未核实商业授权，作者说明其仅供科研；本机附带 FFmpeg 为 GPL 构建。不能把现版视为已经完成商用许可审查。

仓库仅提交源码、测试代码和文档。`SampleSheet/`、MP3、生成的 `.jpu` / `.jianpu`、预览图、模型缓存及虚拟环境保留在本机。新克隆可新建乐谱；歌曲示例和依赖本机音频/谱例的测试，需要自行准备相应文件。

**启动**

```sh
cd /Users/tuxy/Codes/Github3/Music-JianPu
npm run dev
```

需要 Node.js 20 或以上，无需 npm install。打开终端显示的地址，默认 `http://127.0.0.1:5173/`；占用时尝试后续端口。服务由你在终端控制，Ctrl+C 停止。

根地址就是主页。顶部两个标签：**简谱编辑器**（写旋律、歌词、保存文件）和 **听歌记谱 Demo**（导入 MP3、识别主旋律）。切换标签保留当前编辑内容、已选择的音频和识别结果；无需记住子页面地址。旧的 `/?score=…` 乐谱链接继续有效。

[一分钟用户手册](用户手册.md)；界面顶部“一分钟上手”可随时查看。

**简谱播放与 MIDI**

编辑器顶部可播放、暂停/继续、停止，选择从头或当前小节并调整 BPM；播放基于当前音符、调号和时值，修改后重新播放。听歌记谱页也按排好的简谱播放。两页支持标准 `.mid` 下载；浏览器内使用 Web Audio 合成，不依赖插件或硬件。现版不展开反复与结尾括号。

**基本工作流**

- 新建：上方“新建”，设置曲名、调号、拍号及初始小节数。
- 打开：上方“打开”，选择 `.jpu` 或 JSON 文件；“文件”菜单包含最近文件。
- 写谱：工具栏“写谱”，设置时值与八度，按 1–7 或 0 输入。`[` / `]` 缩短 / 延长时值，↑ / ↓ 改八度，`.` 切换附点，Shift + 数字临时使用一半时值。满拍后自动进入下一小节。单声部支持 4/4、2/4。
- 修改：点击音符，在右侧属性面板修改音高、时值、八度、附点；Shift 扩选，用工具栏添加连线。
- 编辑：撤销/重做、剪切/复制/粘贴、全选；点击小节后，用左侧或工具栏“插入小节”在它后面插入；Enter 同样操作。文件末尾追加在编辑菜单。多小节复制按片段粘贴，不覆盖原有声部，超拍会提示。
- 保存：支持系统文件选择器的浏览器中，首次保存选择文件，此后保存写回同一文件。另存为在“文件”菜单。刷新后文件句柄不会持久保存，首次保存可能需要重新选取目标。
- 下载回退：不支持系统文件选择器的浏览器通过下载保存 `.jpu`。界面会显示“已下载”，不会声称已写回项目文件。
- 自动草稿：本地浏览器储存，不等于文件保存；切换文件前会提示未保存更改。清理浏览器储存会删除草稿。
- 导出：文件菜单支持 SVG 和打印 / 保存 PDF，打印按谱行分页。

**歌词**

点击“歌词”模式，再点击谱面已有歌词或音符下方的虚线空格，直接在该位置输入。Enter / Tab 写入并到下一音；Shift + Tab 返回上一音。Esc 放弃当前未提交输入。点击别处或保存时提交输入。中文输入法组合过程中不提交。

可以从点击的位置连续输入中文或空格分隔的音节，文字从此处写入音符。右侧只保留段落切换和辅助操作，不再是主要输入位置。

歌词拖动在音符位置插入排列，目标已有歌词和后续内容向后让位，预览和松手结果一致。右侧可选择「只拖这个字」，包括从同音多字中单独拖出一个字；「当前音符 · 允许多个字」可在同一音符输入多个字。详见用户手册。

支持 1–4 段歌词。歌词使用稳定音符 ID，复制、删除、换行和保存保持关联。右侧“辅助：整段分配”是可选操作；一字多音仍可使用起止音符选区与“拖腔至选区末尾”。

**样例与设计**

“示例 → 我如此爱你 · 旋律与歌词”现载入 `我如此爱你.jpu`，包含原谱两段歌词。输出在 `SampleSheet/我如此爱你/我们的输出/`，原来的纯旋律文件保留。

具体设计见 [工作台设计与功能说明](design/工作台设计与功能说明.md)。原有音乐模型、SVG 排版和文件格式继续沿用。

**验证**

```sh
npm test
```

只运行音乐与工作台模型检查（无需启动服务）：

```sh
node --test tests/model.test.js tests/song.test.js tests/workbench.test.js
```

`scripts/verify-workbench.mjs` 是实际浏览器检查：需要 Playwright 和 Chrome，默认使用本机 Codex 的运行时，也可设置 `PLAYWRIGHT_MODULE`。所有页面请求由本地文件模拟响应，不启动开发服务器或占用开发端口。

编辑器仍不支持多声部、三连音和图片识谱。识别 Demo 支持试听，自动转录的升降号可以保存、显示，并在音符属性里修改。

文件后缀：新建和另存为默认使用 `.jpu`（JianPu）；打开同时兼容旧 `.jianpu` 和 JSON。内部格式标识仍为 `jianpu-melody`，版本为 2。已有旧文件保留。


**听歌记谱 Demo**

新页面 `http://127.0.0.1:5173/transcribe.html`，也可从“示例”菜单进入。本机已准备音频模型；原来运行中的开发服务器需重启一次，加载新增接口。其他机器先执行 `npm run audio:setup`。

歌曲 MP3 先分离人声，再识别单条旋律，显示 SVG 简谱；支持原曲／人声／识别旋律试听、速度调号修改、下载 `.jpu` 和转入编辑器修订。建议先试 30 秒有人声片段。合唱、和声、说唱、残留伴奏及器乐主旋律仍可能导致错误，结果需人工核对。歌曲在本机处理。
