一分钟学会编辑

先点位置，再输入。绿色竖线就是下一个音符的位置。

  1. 插入小节：点击目标小节 → “＋ 插入小节”或 Enter。空小节出现在它后面。
  2. 输入旋律：点击“写谱” → 点击小节空白（末尾）或音符（它后面） → 按 2363；也可点底部数字。用“前 / 后”切换插入方向。
  3. 设置节奏：点顶部时值按钮；键盘 [ 缩短、] 延长，↑ ↓ 改八度，. 切换附点。按住 Shift 输入数字，临时使用一半时值。
  4. 改已有音符：点“选择” → 点音符 → 右侧改音高并“应用”；顶部时值 / 八度按钮直接修改选中音符。
  5. 填歌词：点击“歌词” → 点击文字或虚线空格 → 在谱面原地输入，Enter / Tab 到下一音。拖动时目标歌词向后让位；右侧可选“只拖这个字”或“当前音符 · 允许多个字”。最后点击“保存”。

试一次：点击一个小节 → Enter → 选 ¼ → 输入 2363，就是新小节中的四个四分音符。
