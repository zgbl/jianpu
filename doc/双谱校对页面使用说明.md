# 双谱校对页面

大模型 JSON 点击“生成乐谱”后，视觉稿保存到当前工程并自动打开“双谱校对”。左侧优先读取当前来源的 MP3 识别谱，其次最近完成的识别版本或带录音信息的修订；右侧读取新生成的视觉谱。两侧均可通过下拉框选择其他修订/识别版本，或加载 JPU 文件。缺少 MP3 谱时不会用视觉谱冒充。

默认同步滚动，按各自可滚动高度的比例联动。原歌播放器在页面上方，两侧指针共同使用播放时间；可以点音符定位录音，通过时间校正输入统一调整谱面与录音起点。

“标记差异”比较音高、时值和未匹配音符，着色展示并列出“视觉原值 → 音频候选”。确认音高或确认时值仅改变右侧比较稿，保存到工程的比较工作状态；原始视觉稿与音频稿保留。可撤销确认。只有点“将确认后的视觉谱导入工程”才替换工程主谱，原主谱按现有修订机制保留。

当前是第一版序列对齐，允许漏音/多音；视觉指针时间从匹配的音频音符获得。无录音时间信息时按音频谱 BPM 推算，须人工校准。反复未展开、前奏不同、不同演唱版本或大幅漏音可能错配；指针并不证明匹配正确。当前没有读取原始 f0 重新测音，也未比较歌词和和弦，未匹配音符不自动插入/删除。音频可能错，修改候选不能视作标准答案。

单次比较上限为两谱音符数乘积 400 万；超过后应按片段比较。部分模型输出恢复的草稿也可对照，但缺失的后半段不会凭音频自动补成已完成乐谱。
