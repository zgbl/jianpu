# 音乐文件与其他窗口音频录入

## 网易 NCM

NCM 是加密封装，不是普通 MP3/FLAC。当前程序**不支持直接播放或解密 NCM**。新增导入检查：按扩展名和文件头识别 NCM，给出明确提示，避免把它送入 FFmpeg 后显示难懂的错误。可以导入播放器官方提供的普通音频文件；本实现没有加入绕过保护的解密工具。

## 从另一个浏览器标签页录入

1. 用 Chrome 打开本项目主页，在另一个 Chrome 标签页打开并播放音乐。
2. 本项目音频导入区点 **录制浏览器标签页**。
3. 系统选择框选播放音乐的标签页，勾选 **共享标签页音频**。可以是另外一个 Chrome 窗口中的标签页。
4. 录需要的片段，点 **停止录制**。看音量指示，先用录音播放器试听。
5. 点 **使用录音进行识别**，再点既有的 **识别并提取声部**。音乐有伴奏时保留“歌曲原曲”模式。

当前是“录制 → 停止 → 识别”，不是边播放边实时出谱。最长10分钟，录成单声道 WAV。不会使用麦克风，不会保存屏幕画面；画面共享仅用于浏览器授予音轨的流程。没有取得音轨/未检测到声音会提示并拒绝导入。

浏览器支持存在差异。`systemAudio: include` 只是请求，不保证有系统音频；优先选择 Chrome 的标签页共享。另一个不同浏览器或本地 App 用下面的原生入口。[Chrome官方共享说明](https://developer.chrome.com/docs/web-platform/screen-sharing-controls)、[MDN getDisplayMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia)。

## 从网易音乐等本地 App 录入（macOS）

1. 构建采集工具一次：`npm run audio:capture-setup`。需要 macOS 和 Xcode Command Line Tools，代码使用 macOS 13+ ScreenCaptureKit API。本次在当前机器已成功编译，生成 `.cache/bin/audio-capture`。
2. 在你自己的终端重新启动 `npm run dev`，刷新主页，加载新增服务接口。
3. 打开并播放目标 App 的音乐，本项目点 **选择本机 App**。
4. 首次按 macOS 提示允许 **屏幕与系统音频录制**；若拒绝，去“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”检查实际提示中的应用/终端，必要时按系统要求重开服务。
5. 选目标 App，点 **开始录制这个 App**。另一个浏览器播放音乐也可以选那个浏览器 App；该 App 的其他有声标签页可能同时混入，录制时暂停它们。
6. 点 **停止录制 → 试听 → 使用录音进行识别**。

使用苹果原生 ScreenCaptureKit 的应用过滤和音频输出；不安装虚拟声卡，不采集麦克风，不写视频文件。本机 App 录为 AAC/M4A。系统保护、目标程序行为及授权可能造成无法采集或无声，必须先试听，不能把编译通过视为网易音乐实测成功。[苹果 ScreenCaptureKit 文档](https://developer.apple.com/documentation/screencapturekit)。

## 保存与代码

录完仅在采集预览中还不算已加入工程。点“使用录音进行识别”后，录音进入现有原曲导入流程，存入工程的 `audio/original.wav` 或 `.m4a`，可与识别结果、人声等一起保存 `.jpp`。工程已有另一首原曲时，沿用原逻辑新建工程，保留旧工程。

| 文件 | 职责 |
|---|---|
| `src/audio-capture.js` | 标签页/App录制面板、授权流程、计时、停止/取消、试听与导入 |
| `src/capture-worklet.js` | 浏览器音轨采样；不向扬声器回放采集内容 |
| `src/capture-audio.js` | PCM→WAV、NCM导入检查 |
| `native/AudioCapture.swift` | 列出App，ScreenCaptureKit按App采集，AVFoundation编码M4A |
| `audio/capture-api.mjs` | 本机采集任务、停止/取消、超时、读取录音；不使用云端 |
| `scripts/setup-capture.mjs` | 编译系统采集工具，不执行录音 |

`.audio-captures/` 是本机临时录音目录，`.cache/` 保存编译工具；这两处及 `.ncm` 均已忽略，不上传 Git。未导入的浏览器录音不跨页面恢复，使用之前先导入工程。

## 出现 “The user declined TCCs…”

这表示 macOS 拒绝屏幕/系统音频访问；还没有取得App列表或开始录音，单纯重复点击不能解决。

1. 保存正在编辑的工程。打开“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”。
2. 允许**启动开发服务的应用**。从 Terminal 执行 `npm run dev` 时通常是“终端”；从 iTerm 启动通常是 iTerm。以系统权限列表实际显示的程序为准，采集工具也可能单独显示。不需要给播放音乐的网易音乐打开该权限。
3. 若系统要求退出并重新打开获授权的应用，按提示操作；再由你自己运行 `npm run dev`，刷新页面，点“选择本机 App”。
4. 如果列表没有对应程序，检查首次授权提示；当前页面会显示中文说明和设置入口。不要重置全机TCC权限。

这是系统授权门槛，程序不能自行授予权限。此次没有改系统权限、运行真实采集或操作5173服务。启动应用的具体归属未能从受限环境读取，不能断言设置中一定显示哪个名称。[Apple官方权限设置说明](https://support.apple.com/en-gb/guide/mac-help/mchld6aa7d23/mac)。
