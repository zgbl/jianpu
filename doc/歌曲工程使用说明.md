# 歌曲工程：一分钟上手

1. 打开主页，点 **新建工程**，输入曲名。选择“听歌识别”或“空白简谱”。
2. 在同一工作台导入 MP3，设置片段范围，识别并试听人声、简谱。
3. 识别结果就在下方可编辑谱面上。用工具栏选择“选择 / 改音”“写谱”“歌词”“小节线”，原地修改；双击有来源时间的音符试听，不跳转另一页。
4. 工作内容自动保存到本机。需要备份、移动或换电脑时，点 **保存工程**，保存完整 **`.jpp`** 文件。
5. 下次点 **打开 / 最近工程**，选择本机工程，或“打开 .jpp 工程包”。恢复谱面、设置和试听位置，播放保持暂停。

**保存什么？** 原始完整音频、成功识别的片段 WAV、人声 WAV、选择的模型输出的鼓/贝斯/吉他/钢琴/其他声部 WAV、原始音高结果、识别预览谱、人工修订谱、排谱参数、选区和缩放。模型和运行环境不装进工程包。

提取吉他等声部的操作见[多声部提取与试听](多声部提取与试听.md)。

## 两种保存

| 操作 | 用途 |
| --- | --- |
| 自动保存到本机 | 写入项目运行目录的 `.projects/`，刷新、关闭浏览器后可继续 |
| 保存工程 / 另存为 | 写出完整 `.jpp` ZIP 工程包，用于备份和携带 |
| 下载 .jpu | 只导出当前乐谱，不包含音频或识别记录 |

`⌘/Ctrl + S` 保存工程；`Shift + ⌘/Ctrl + S` 另存为。支持系统文件选择器时选择目标文件，此次打开期间可继续写回；不支持时下载 `.jpp`，界面明确显示已下载。重新打开页面后可能需要重新选择保存位置。

本机自动保存不代表外部工程包已更新，携带前再保存一次。识别中可以保存原曲和设置；该次任务完成后再保存，才会包含完整人声和结果。

## 修改和重新识别

当前显示的谱面就是当前工程主谱；识别结果自动进入这张谱面，无需“采用”或跨页传递。音符、歌词、小节线编辑立即自动保存。修改 BPM 设置后点“按手工速度和拍号重新划分全曲”，或按人工边界重排；重新识别／重排从保存的原始候选音符生成新谱，已有修改保留到顶部“修订版本”，可恢复，最多十份。

导入另一首原曲会建立新工程。打开 `.jpp` 也建立本机新副本，不覆盖已有工程。多个窗口同时编辑同一工程时，冲突会提示，避免覆盖另一窗口的谱面。

改版前的识别可以在“打开 / 最近工程”内展开“恢复改版前的识别任务”，查找旧任务。只有旧任务缓存仍存在且识别完成，才能找回音频；仅有 `.jpu` 时无法补出原曲或人声。

## 当前边界

- 已完成工程无需模型即可恢复、试听和编辑；重新识别仍需本机 Python 和模型环境。
- 服务中断的识别会标记为中断，需要重新识别；目前不从模型内部或中途的人声文件断点续算。原曲和之前成功的结果保留。
- 撤销/重做栈不跨页面重开；当前修订谱和采用新结果前的保留版本会恢复。
- 原曲最多 100 MB，每个工程最多三十次识别；导入工程包限制 2 GB、256 个文件，并校验资产大小、SHA-256 和路径。
- 工程包中的 `recognized.jpu` 是该识别版本最新排谱预览；原始未量化结果保留在 `result.json`。

## 播放与全曲

原曲、人声、贝斯、鼓等音轨及简谱播放都支持空格暂停／继续，焦点在谱面、音轨按钮或主页时均可使用；文字输入框保留普通空格，中文输入法组合状态不触发播放。选择“全曲”从原曲开头识别，最多处理 10 分钟。

谱面右侧保留“识别人声歌词（建立时间锚点）”入口，它调用原来的本机歌词识别，随后可粘贴完整歌词校准；不需要滚回页面上方找按钮。

## 谱面直接编辑：一分钟

- **改音**：点音符，按 0–7 改音高；工具栏修改时值、八度和附点。Delete 删除音符，撤销按钮恢复。
- **写谱**：点“写谱”，点输入位置，按 `2363` 连续写入；鼠标数字按钮同样可用。`[` 缩短、`]` 延长时值，↑↓ 八度，`.` 附点。插入位置可选所选音前／后。
- **空小节**：点目标小节或音符，点“＋ 空小节”（或 Enter），新小节出现在当前小节后，随即可以写谱。
- **小节线**：选线后 Delete 或“删除小节线”合并两侧；选音符后“＋ 小节线”在它前面拆开。也可进入“小节线”模式直接点音符插入。抓住线或底部小圆点拖到相邻小节内的音符前，松手保存；跨系统换行也可拖。不能越过另一条线；需要跨越时先删除中间线。终止线保留。
- **歌词**：点“歌词”，点文字或虚线空格，在谱面输入，Enter 保存。一音可以填多个字。拖动文字时，目标文字向后让位；“只拖这个字”可拆开多字词组逐字挪动，默认本行后续歌词跟随。

人工小节线修改仅重新分组现有音符：保留音符 ID、来源时间、歌词和连线，允许暂时超拍或不满拍，显示实际拍数提示。手工合并后 MIDI 按现有音符时值连续播放，不插入额外静音。需要重算全曲时，左侧会得到编辑边界对应的时间与小节数，也可自行标定、修正。

旧 `editor.html?score=…` 链接重定向到统一工作台。主页不再加载独立编辑页，也不再有两个工作阶段标签。
