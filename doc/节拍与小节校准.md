# 节拍与小节校准

## 一分钟使用

1. 在“听歌识别”打开工程，点 **分析贝斯／鼓并重新划分小节**。不重新分离人声或识别音高，只分析已保存的鼓声；没有鼓轨时使用原曲片段。默认选取稳定的连续 10–20 小节拟合平均时长，并用固定小节网格向前后推算；不足 10 小节时会注明仅用短片段估计。
2. 播放原曲或鼓轨核对速度。候选速度允许检查一倍／半倍；选择其他速度会改用固定速度时间轴，主候选可恢复固定小节模式；“跟随伴奏拍点”仍可用于实际有速度变化的演唱。
3. 听到明确的小节第一拍，暂停播放器，点 **当前位置是小节第 1 拍**。也可以直接填写片段内的秒数，或点 **小节线提前／延后一拍** 整体移动小节线。
4. 用人声与橙色谱面指针对照，确认后进入编辑并采用新草稿。校准参数、检测拍点及草稿随工程保存。已有编辑页的修订不会因分析而被覆盖。

旧工程需要先重新分析节拍。新识别默认使用固定小节平均网格。拍号目前支持 4/4、3/4、2/4。手工速度、人工边界和有声节拍器见 [人工小节划分](人工小节划分.md)。自动强拍是候选，页面会显示“待试听确认”，不能视为已经确定。

## 修正了什么

旧算法仅从整曲能量自相关估计一个 BPM，并默认把第一个识别音符设为小节第一拍。它没有识别伴奏拍点，可能错误选择倍速；前奏、弱起、半拍进歌和现场速度变化会使小节线错位。

新流程将节拍识别与人声取音高分开：

- `audio/rhythm.py`：优先分析 Demucs 已分离的鼓轨。降采样后计算频谱正向变化和低频变化，寻找多个速度候选，比较多个时间窗口中的周期一致性；用动态规划寻找允许局部速度变化的逐拍时间轴。相近的一倍／半倍候选会标记歧义。根据循环重音和贝斯的低频起音共同推测 4/4 小节相位，仍保留“未确认”状态。`stable_grid` 从连续 20 小节做稳健线性拟合，排除加花等异常拍点，合并相近的稳定窗口时长，固定周期后向全曲投影。原始拍点也保留，供允许速度变化的模式使用。
- `audio/transcribe.py`：新识别结果记录 `rhythm`，包括 `beatTimes`、建议 BPM、候选速度和临时强拍相位。
- `POST /api/audio/rhythm`：旧工程利用本地保存的 WAV 重新分析，不必重跑人声分离和音高模型；接口仅接受已完成任务及本机请求。
- `src/beat-grid.js`：把音频秒数与拍坐标双向换算，拍点间分段插值。小节起点独立于第一人声音符，手动校准只改变拍的相位。
- `src/transcription-score.js`：将旋律放到十六分拍网格，跨小节拆分长音；过密的候选音落在同一个格时保留更可靠的候选，并提示，避免后续音符被强行向后挤移。
- `src/audio-score-cursor.js`：新谱的 `gridTimeStart` / `gridTimeEnd` 记录书写拍位对应的实际时间，游标跟随这些拍位。原始 `sourceTime` / `sourceEnd` 保留给试听与歌词对齐。

节拍数据保存在识别结果、识别版本的排谱参数与工作状态中，随 `.jpp` 恢复。不会静默重写原始音乐或已有编辑谱。

## 美若黎明检查结果

用户提供的工程中，旧草稿 157.9 BPM、141 个旋律小节；已保存的鼓轨重新分析得到约 79 BPM，改为 71 个旋律小节。旧结果存在约两倍速度错误。

校正版保存为单独的本地工程包，保留原曲、所有已提取声部和识别结果。这证明修正了倍速与排谱时间轴，不证明每个音符和小节强拍都已人工听审正确。主旋律从约 27.52 秒开始；新谱保留其小节内实际拍位，不将它强制设为第一拍。

## 验证及限制

`node --test tests/beat-grid.test.js` 检查弱起、跨小节、现场速度插值、小节相位调整和短碎片不挤移后续音符。`python scripts/test-rhythm.py` 使用已知 79 / 96 / 120 BPM 的合成音频，检查速度及拍点误差；静音不产生伪造拍点。`scripts/verify-rhythm.mjs` 使用实际工程验证分析、校准、候选速度、保存、恢复和游标，不启动开发服务器。

复杂切分、无鼓伴奏、自由速度及拍号变化仍可能失败；当前不自动处理拍号变化，也不保证自动强拍是正确的。未检测到拍点时可填写固定 BPM 和一个确切的小节第一拍。

这是项目自写的节拍分析代码，使用音频环境中已有的 NumPy、SciPy、SoundFile，不增加模型或云端服务。无需下载新模型。后台新增了接口，更新后需要用户自行重启 `npm run dev`。

最新美若黎明固定网格：79.0035 BPM，4/4 每小节 3.03783952 秒，20 小节估计窗口约 81.06–141.79 秒；窗口中位残差约 12 毫秒，这是对检测拍点的拟合残差，并非人工听审准确率。固定时长与小节第一拍是两个不同问题，仍允许校准强拍起点。
