# 音频识别调试工作台

在歌曲工程顶部点击「音频调试」。使用已有识别结果，不需要重新识别整首歌。旧版本没有保存逐帧数据时，页面明确提示仅有抽样数据；没有保存的稳定核心不会伪造。

## 第一次看一个有问题的音

1. 切换到需要检查的识别版本和「提取人声」。点击音高图上的音符，或在右侧选择音符。
2. 查看蓝色原始音高点与绿色目标音符矩形。绿色粗线是稳定核心，右侧显示具体起止时间。
3. 点击「试听选区」，再点击「试听选区识别音符」，对比人声与合成目标音。两者均带播放指针。需要多听几次时点「循环试听选区」；取消循环复选框即可关闭循环。
4. 点击「选择稳定核心」可以只听平台部分，避开起音滑音。也可拖动图形重新圈选，或输入原曲起止秒数。
5. 打开「显示局部频谱」，看同一时间有哪些频率能量。泛音、伴奏残留与歌声音高可能同时出现；最亮频率不一定是基频。
6. 可导出选区诊断 JSON，包含帧数据、音符、参数和统计，供后续分析使用。

## 坐标和颜色

- 全部图形横轴均为原曲秒数；播放器播放的是识别片段，其播放秒数会加上片段起始偏移后显示为指针。
- 波形左轴是振幅。放大 ×2/×4/×8 只改变图形比例，坐标标签同步变化，不改变播放音量。超出当前图形比例的波峰会被裁切。波形是浏览器解码后的单声道下混；解码采样率在参数区显示。
- 波形蓝线是识别器记录的人声 RMS，使用独立右轴。切换原曲波形时，这条 RMS 仍是人声分析数据，不是原曲 RMS。
- 音高图左轴是绝对音名，右轴是 Hz，不随调号或 Capo 更换；A4 = MIDI 69 = 440 Hz。
- 蓝色点是原始有声帧；灰点是无声帧的音高猜测。灰点不是可靠的音符。
- 绿色矩形表示演唱范围；粗绿色线表示稳定核心。分段目标帧是已有算法输出的离散目标，不是第二套独立检测结果。
- 只有当前谱明确来自所选识别版本时，才可以叠加紫色虚线的谱面量化范围；人工插入、丢弃或缺少时间数据的音可能没有对应。
- 黄色区域是研究选区；红色线是播放指针。

## 操作与限制

概览点击移动观察窗口。＋/－放大缩小，拖动圈选，双击已选音符放大。滚轮平移，Ctrl/⌘＋滚轮缩放；←/→逐音查看，空格播放/暂停（输入框操作时不抢快捷键）。所有显示复选框都可再次点击关闭。

频谱由本机后台 worker 计算，一次最多 30 秒。分析窗 1024/2048/4096 与原识别器窗独立：较长窗提高频率分辨率，同时混合更长的声音时间。频谱展示 Hann 窗频率分量幅度（−80 至 0 dBFS），用于观察，不是新的音高识别结果。切换频谱窗不会重新识别音符。

有声概率表示这一帧可能有声，不等于音高正确率。选区中位数和音高中位绝对偏差用于研究；多个音符、滑音和混响混在一起时，不能拿它们直接替换正确音高。

本页仅检查和试听，不修改音符、分段、调号或工程内容。下一步是否调整算法，应根据这里看到的实际证据决定。

### 识别简谱与声音逐音对照

音高图下新增时间对齐的简谱行。可切换「当前工程谱（随编辑更新）」和「此版本原识别谱」；当前工程谱必须关联选中的音频识别版本，避免把视觉导入谱误当作音频识别结果。

简谱与波形、音高曲线共用原曲秒数及观察窗口。音符左边界对应录音起点，横向宽度表示录音时长；减时线、附点、八度点和三连音标记表达谱面时值。显示歌词和小节编号，播放时同一时间的音符变绿并有红色指针；点击音符选中对应声音，双击放大，滚轮平移和缩放。密集音符请放大查看。

优先使用谱音的量化录音时间，否则用原始演唱时间。片段偏移仅加一次。手工前后增补音符按邻近录音锚点估算，并用虚线提示；没有可核实录音位置的音符不会按小节编号伪造时间。谱源标题显示有时间定位的音符数量。编辑谱后返回调试页会更新当前谱行。
