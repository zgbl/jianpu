# 音轨与谱面播放游标

播放人声轨时，橙色竖线在乐谱上随音频时间移动；暂停时停住，拖动音频进度后立即定位。跨行时跳到下一行，播放到屏幕外的行会自动滚动。原曲试听也使用同一时间对应关系。

听歌识别页点击识别音符，可从该音符的实际来源时间开始试听；跨小节的延音片段分别定位。编辑页保留选择、写谱、歌词操作，用“对照原曲”试听选中音符。

`src/audio-score-cursor.js` 从 `audio.currentTime` 读取进度，每个动画帧更新 SVG 竖线。原曲减去识别片段的 `clipStart`，分离声部从零开始；修改谱面 BPM 不会改变音轨的来源时间。

按伴奏节拍校准的新谱使用 `gridTimeStart`、`gridTimeEnd` 将播放时间映射到实际书写拍位，小节边界以检测的拍点为准；因此指针也能暴露音符排在错误拍位的问题，不再仅按原始音符时间迁就谱面。

旧版识别音符的 `sourceTime`、`sourceEnd` 保存原始时间；同一个源长音拆为多个延音符号时，按书写时值分配该长音的时间。休止符按前后源音之间的真实静音分配。没有来源时间的手工音符无法可靠对应原歌声，因此不伪造其对应位置。此游标不会写入乐谱文件、导出 SVG 或打印内容。

验证：`tests/audio-score-cursor.test.js` 检查时间插值、跨行延音、休止及未关联音符；`scripts/verify-stems.mjs` 使用真实声部音频检查移动、暂停、跳播、原曲片段偏移和编辑页。浏览器测试不启动开发服务器。
