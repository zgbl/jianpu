# 歌词锚点补全与逐字拖动

操作：刷新页面，打开原工程；保留粘贴的完整歌词，点击「按正确歌词校准并排谱」。文字与已有声学结果相同时直接复用现有锚点，不重新运行模型。

全部文字先铺排。两锚点之间按字符序号插值；首尾按锚点间字符时长中位数外推；无锚点时使用明确标记的初排。黑色为可靠声学定位，棕色为估算，估算不代表识别正确。

按住谱面上的一个字拖动并松手，可跨行，也可放在休止符下面；仅该字移动，保留落点的水平偏移，不要求一音一字。支持撤销和重做。保存工程保存人工位置，重开工程恢复。再次应用相同歌词保留已有人工位置。

数据：`lyricAlignment.characters` 保留字符 ID、原始声学证据和估算时间；人工位置单独存入 `placement:{noteId,offsetX,manual:true}`，不修改声学时间或旋律。显示独立字符，不再因附近没有音符而遗漏歌词。

验证：当前《你的背包》工程只读复制测试，215 字全部生成位置，其中 133 字为声学定位、82 字为估算，SVG 输出 215 个逐字拖动目标。现有服务实际测试横向及跨行单字拖动、松手后位置保留。自动测试覆盖锚点保留、漏字插值、重复字、无锚点初排、单字移动与 JSON 保存恢复。尚未逐字试听验证估算时间。

## 紧凑排版与短休止整理

刷新即可采用通常每行四小节、密集时三小节的布局；末行和手工指定换行允许不足三小节。谱面工具栏「整理短休止」用于已经保存的识别谱，支持撤销。仅处理不超过半拍且原始事件空隙不超过 0.3 秒的短休止，保留较长停顿。处理保持每小节总时长，不移动后续音符起点。新识别／重排在生成阶段使用同样的短空隙延续规则。人工标记的事件不参与自动延续。

当前《你的背包》保存谱的只读测试：104 小节排为 26 行，每行四小节；可整理 62 个短休止，休止符从 213 减为 151。剩余休止包含前奏、长停顿、缺失旋律段，不能仅凭排版判断为前音延长。未试听确认这 62 处均为持续歌声。
