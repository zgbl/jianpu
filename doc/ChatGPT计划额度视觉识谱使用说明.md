# ChatGPT 计划额度视觉识谱

视觉识谱页支持用 ChatGPT Plus / Pro 账号授权，让本机应用调用账号当前提供的模型和计划额度。它与 OpenAI API Key/API 余额分开，不要求把 Key 粘贴到页面或写进 `.env`。

## 首次使用

1. 确认本机是 macOS，已安装 Node.js 22 或以上。
2. 在项目根目录运行一次 `npm install`。更新本功能的 TypeScript SDK 源码后，再运行 `npm run build:chatgpt-auth`。
3. 按项目平时的方式启动服务，然后打开“视觉大模型识谱”页面。
4. 模型服务保持为“ChatGPT Plus / Pro（登录授权）”，点击“继续使用 ChatGPT 登录”。应用会打开系统浏览器。
5. 在 OpenAI 授权页登录你的 ChatGPT 账号，检查授权内容，并明确允许使用 ChatGPT 计划额度。完成后返回本机页面。
6. 页面显示已连接及可用模型后，选择一个模型，添加一张或多张简谱图，点击“识别全部图片”。之后仍可标记有问题的小节并提交局部复核。

授权页若只完成账号身份验证、没有开放计划额度，页面会显示“账号已连接，但尚未授权计划额度”。点击“启用 ChatGPT 计划额度”重新打开授权页，并选择对应权限。若账号未包含 Plus / Pro 计划、该功能对账号暂不可用，或组织策略不允许，页面会显示授权/服务错误；此时仍可选择 Gemini、OpenAI API、Qwen 或 DeepSeek 等 API 服务商。

## 隐私和断开

模型识谱会把所选图片和简谱 JSON 规则提示发送给 OpenAI 的模型服务。此功能不会读取工程音频。授权凭据保存在当前 macOS 用户目录的应用配置文件中，并使用 macOS 钥匙串中的本机密钥加密；凭据不会发送到浏览器页面。点击“断开 ChatGPT 登录”可撤销本机保存的会话。也可在 ChatGPT 账号的已连接应用设置中撤销授权。

## 故障处理

- **识别按钮不可用**：先确认页面显示“已连接”且已选中模型。
- **登录后仍提示未授权计划额度**：点击“启用 ChatGPT 计划额度”，在授权页重新确认计划使用权限。
- **模型列表读取失败**：保留页面显示的错误文字，重新加载页面；若持续失败，断开后重新连接。
- **等待时间过长**：状态行会显示已等待时长；点击“取消等待”可中止请求而保留现有谱面。
- **服务端未识别新路由**：依赖或服务端代码更新后，需由用户在自己的终端手动重启本地开发服务。本说明不会自动占用或重启开发端口。
