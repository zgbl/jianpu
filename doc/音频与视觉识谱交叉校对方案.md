# 音频与视觉识谱交叉校对方案

## 本轮实现与边界

新增 6/8 拍：JPU 为 `meter:[6,8]`，一小节六个八分音符、48 个内部时值单位。四分音符仍为 16 单位。涵盖编辑拍号、新建、视觉导入、容量校验、音频重排、谱面显示、MIDI 拍号和播放。
播放与音频内部 BPM 始终表示四分音符；例如 6/8 大拍（附点四分）每分钟 80 次，需要选择附点四分拍子单位，换算为 120 四分音符 BPM。不要只改变拍号就认为原来的音符时值会自动改对。
当前音频排谱使用十六分网格，尚无三连音数据结构、括号和数字 3、专门播放时值或自动三连音识别。6/8 的普通八分音符可以直接表示三等分大拍。4/4 与 6/8 不是简单更换标题便能互换；须比较实际重音、乐句和速度单位。

## 目标与主稿

两个结果在同一工程中保留，互不覆盖。视觉识别作为可编辑主稿；音频保留原始 f0、稳定音核心、置信度、起止时间、人声片段和拍点。不要拿音频生成的简谱作为唯一证据：其中已有取整、漏音和错分小节。
同一歌曲可能有不同版本、变调、前奏长度、反复或编曲。先确认版本和片段对应关系，再比较。用户认为视觉错误更少是采用主稿的依据，不能视为每个音都正确。

## 第一阶段：对齐，不修改

1. 将视觉数字按实际 Do、八度、升降号转为绝对音高，保留指型调与 Capo 的独立配置。以旋律音程序列和时值比例匹配音频稳定核心；先估计整体移调，不能用强制换调掩盖局部误差。
2. 用多处可靠旋律和歌词片段做锚点，通过允许插入、删除的动态序列对齐匹配；局部时间伸缩适应真实演唱。歌词作为辅助，不能强迫一字一音。
3. 分段展开反复并保存“谱面小节 → 演唱第几次”的映射；保留一字多音、延音、多段歌词。无法确定的反复或版本差异应让用户选择。
4. 为主稿音符附加音频起止时间和对齐置信度，不改变原音符。试听时指针跟随，支持点小节听对应人声。

验收：人工选三至五个分散锚点核对，跨副歌、反复后仍正确；不能只有开头对齐。

## 第二阶段：生成疑点

| 疑点 | 音频证据 | 推荐操作 |
|---|---|---|
| 视觉漏音 | 两个已对齐音之间存在独立、稳定且高置信的核心 | 提议插入，不把滑音当漏音 |
| 视觉多音 | 小音符找不到独立核心 | 标记；装饰音、弱唱不能直接删除 |
| 八度错 | 多次演唱稳定差 12 半音 | 提议八度修正，同时检查检测器八度错误 |
| 半音错 | 稳定核心长期支持另一音高 | 显示 cents、调律校正和人声试听；不直接吸附调式 |
| 时值/减时线错 | 相邻可靠起音与局部拍网格支持其他时值 | 提议时值变化；演唱拖拍不能直接当印刷错误 |
| 小节线错 | 主稿拍数不符，邻节也不符且对齐支持移动边界 | 给出前后比较；弱起不自动补休止 |
| 歌词错漏 | 视觉字序与听音文本或人工歌词不一致 | 提示待确认，音频 ASR 不能作为真值 |

和弦优先保留视觉字母，音频旋律不能唯一确定和弦；伴奏和声验证是后续独立任务。

## 第三阶段：人工确认与视觉局部复核

增加“交叉校对”页：左侧原谱裁图，中间主稿小节，右侧人声试听与 f0 曲线。每条建议列出原值、建议值、音频依据、对齐置信度、原图位置；提供接受、拒绝、暂缓。接受后保存修订版本，支持撤销。
可把有疑点的小节裁图和音频证据摘要送回视觉模型，要求重读图而非迎合音频结论。禁止因拍数不满就自动发明音符。先以用户确认闭环收集样本，再决定是否开启高置信自动修正。

## 数据建议

单独保存 `crossReview`：视觉稿修订 ID、音频 runId、调律/移调估计、反复映射、锚点、匹配表与疑点列表。
匹配表记录 `noteId`、音频稳定核心 ID、起止秒、置信度、音高差与时值差。疑点记录小节 ID、候选变更、证据引用和接受状态。原始两个结果均保留；主稿改变后旧建议失效，不能反复应用。

## 实施顺序与验收

先做一个已知片段的手工锚点对齐与同步试听，再做只读疑点列表，最后实现单项确认和视觉局部复核。不先做全曲自动合并。
选取包含 6/8、4/4、反复、滑音、弱起的测试集，人工标注视觉已知错漏。评估对齐误差、漏音发现率和错误修正率；重点统计“把正确主稿改错”的次数。对齐失败必须停止建议。本文是下一步设计方案，本轮未实现交叉校对功能。
