# 人工校准小节与有声节拍器

## 一分钟操作

在「听歌识别」打开工程，在左侧「排谱设置」查看当前检测 BPM。所有 BPM 都以四分音符为一拍。

**已经知道正确速度：**填写「手工速度 BPM」，选 2/4、3/4 或 4/4，设置一个准确的「小节第 1 拍时间」，点「按手工速度和拍号重新划分全曲」。例如 120 BPM 的 3/4，每小节 1.5 秒；4/4 每小节 2 秒。这个按钮直接采用手工速度，不受原来检测的倍速或半速影响。

**不知道速度，但能听出小节：**点「开始标定小节边界」，点击谱面音符，在音符前标出红色边界；标一行的起点和后续小节线。也可暂停原曲、人声或乐器轨，点「当前位置添加小节边界」。默认每次相隔 1 小节；如果只标一段的两端，而中间实际有 3 小节，第二次添加前将间隔设为 3。列表中可直接修改秒数和相对小节编号，或点「移动」后点新的音符，或删除错误边界。

标完后点「按人工划分重新分配全曲」。系统计算新的 BPM、小节时长和第一拍位置，并向前后推算全曲。至少需要两个边界；连续多条准确边界更可靠。现有「分析贝斯／鼓并重新划分小节」按钮在有两条人工边界时，也会优先使用人工标定。点「撤销全曲重新划分」恢复上次排谱参数，保留标记供再次调整。

**听着核对：**点「有声节拍器」。首拍高音、其余拍低音，音量可调。先播放原曲、鼓声或人声，再开启节拍器，它会使用音轨当前时间和小节起点同步打拍。暂停音轨时停止打拍，继续、跳转时跟随；没有播放音轨时可独立打拍。空格暂停／继续，文字输入框中空格仍用于输入。所有编辑都在同一张谱面进行。

当前谱面就是可编辑主谱。直接插入、删除或拖动小节线只改变音符分组，保留音符与歌词。全曲重排从原始候选重新生成谱面，旧的人工编辑谱保留在「修订版本」中。标记、排谱速度、拍号和校准结果随工程保存，导出 `.jpp` 后下次可以恢复。节拍器开关不保存，打开工程不会自动发声。

## 实现

- `src/manual-bars.js`：对人工边界的时间与相对小节编号做加权直线拟合，斜率为每小节秒数。`BPM = 60 × 每小节四分音符数 ÷ 每小节秒数`。检测拍点仅能在人工确定的周期内微调，不允许把人工确定的三个小节再次合并为一个。超出速度范围、编号／时间逆序或明显不一致的标记会报错，保留旧结果。
- `src/transcribe-app.js`：标定、修改／移动／删除、撤销、保存恢复、手工速度重排；原始候选音符不变，重新量化到新的拍网格，重新拆分跨小节音符。歌词继续通过原始音符时间重新对齐。
- `src/transcription-score.js`、`src/beat-grid.js`：固定周期排谱、源音频秒数与拍位换算，支持 2/4、3/4、4/4，最多 1000 小节。
- `src/metronome.js`：本机 Web Audio 正弦振荡器生成短音，首拍 1500 Hz、其他拍 950 Hz；每 25 毫秒检查音频时钟并提前约 100 毫秒调度。音轨暂停时取消已调度声响，跳转后重新计算拍位。不使用云服务、模型或音色下载。

红色人工线显示在最接近标记时间的原始音符前。若真正小节线处没有音符，使用暂停音频的准确位置或修改列表秒数；数值时间才是计算依据。

固定周期适用于节奏稳定的歌曲。自由速度、渐快渐慢或途中变拍号仍需分段处理；这一版只采用全曲统一速度和拍号。功能测试能验证重排规则，不能代替听审确认这首歌的实际速度和强拍。

## 验证

`node --test tests/manual-bars.test.js` 验证人工 3 小节跨度、周期优先级、不一致标记、3/4 与长曲排谱。

`RHYTHM_TEST_PROJECT="路径/歌曲.jpp" node scripts/verify-manual-bars.mjs` 使用真实工程的临时副本验证谱面标定、手工重排、撤销、保存恢复和有声节拍器。测试标记是模拟人工输入，用于验证计算规则，不代表这首歌已经人工校准正确；不启动或占用开发服务器。
