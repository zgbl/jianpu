**谱间工作台：重设计与基本编辑功能**

**设计诊断与改动**

原界面把文件按钮、输入设置、音符修改、倚音与反复操作同时展开在谱面上方，缺少清晰的文档状态和选区上下文，实际谱面被挤到下方。

新版采用固定工作台：顶端文件栏与菜单，下方紧凑工具栏；左侧小节导航，中间可缩放谱面，右侧属性/歌词面板。高级结构与倚音在属性面板折叠展示，示例移入菜单。谱面和面板分别滚动，底部常驻输入音符与状态栏。

色彩为石墨文字、浅灰工作区、白色纸面与低饱和绿色选区。中文品牌使用宋体，操作界面使用系统中文无衬线字体，音乐数字继续保留独立字体与绘图定位。图标为统一线宽的本地 SVG，无远程字体或图标依赖。

**已实现功能**

| 工作 | 功能 |
| --- | --- |
| 文件 | 新建、打开、保存、另存、最近文件、未保存提示、文件名与保存状态 |
| 文档 | 曲名、调号、拍号、自动草稿及旧草稿读取 |
| 编辑 | 撤销重做、剪切复制粘贴、全选、音符删除、多小节片段粘贴 |
| 小节 | 新增、插入、删除、补休止、反复起止、终止线、换行 |
| 视图 | 缩放、适合宽度、导航及属性面板显示控制 |
| 歌词 | 逐音输入、中文输入法、Enter 到下一音、连续分配、4 段歌词、一字多音拖腔 |
| 输出 | 原生 JSON、SVG、打印及浏览器保存 PDF |

保存优先使用浏览器 File System Access API，写入前检查已有句柄的写入许可；不支持该 API 时下载文件，并明确显示“已下载”。文件句柄未用 IndexedDB 持久化，因此重新打开页面后可能需要再选择保存目标。原生文件保存、浏览器草稿、最近文件副本是三个不同状态。

自动草稿保存当前内容和文件保存基准，恢复后能继续显示未保存状态。取消文件选择或保存失败不会把文档标记为已保存。

**数据与代码边界**

沿用原生格式版本 2，新增可选的 `lyrics` 字段。没有歌词的旧文件直接打开，不需要迁移。

```json
{
  "lyrics": [
    { "noteId": "m5n1", "verse": 1, "text": "你" },
    { "noteId": "m5n5", "verse": 1, "text": "处", "endNoteId": "m6n1" }
  ]
}
```

`noteId` 绑定起音，`verse` 为 1–4，`endNoteId` 是可选的拖腔终点。歌词不能绑定休止符，段落与音符组合必须唯一，拖腔必须向后。导入校验全部端点。

- `lyrics.js`：歌词验证、音节切分、连续分配。
- `commands.js`：新建、小节操作、休止填充、结构化复制粘贴。
- `files.js`：系统选择器保存、写入许可与下载回退。
- `app.js`：界面、选区、编辑事务、撤销、草稿和文件生命周期。
- `layout.js`：考虑歌词最小宽度，按歌词段数扩大行距。
- `render.js`：在低音点下方逐段绘制歌词，跨行拆分拖腔，使用与旋律相同布局导出。

歌词没有保存页面坐标。复制片段时重新分配音符 ID，同时重新映射内部音乐连线、歌词和拖腔；片段外的拖腔端点不带入。删除音符时清除其歌词及关联的拖腔终点。

**使用与验证**

用户自行运行 `npm run dev`。开发过程中不启动用户的预览服务。独立无头浏览器的网络请求直接由项目文件模拟响应，避免占用用户测试端口。

模型检查覆盖歌词往返、休止与延音续音过滤、超范围分配拒绝、复制粘贴 ID 重新映射、删除清理、多段行距和长歌词占位。浏览器检查覆盖原生保存、下载回退、另存取消、未保存保护、新建、连续写谱、歌词编辑、最近文件及完整歌曲预览。

现有音乐范围仍为单声部、2/4 或 4/4，暂无试听、复杂连音组或多声部。打印通过浏览器按整条谱行分页，不提供专门的出版级分页引擎。

文件后缀：新建和另存为默认使用 `.jpu`（JianPu）；打开同时兼容旧 `.jianpu` 和 JSON。内部格式标识仍为 `jianpu-melody`，版本为 2。已有旧文件保留。

**编辑位置与键盘规则（更新）**

默认写谱模式。小节插入统一位于当前小节后，末尾追加单独放在编辑菜单；Enter 在谱面上插入小节。插入位置由当前小节、所选音符与前/后方向确定，绿色光标指示边界。点击小节空白在末尾输入；Home/End 切换本节首尾。数字插入后推进位置，时值与八度保持，不随写谱时的选择改变。选择模式则将顶部时值和八度应用到所选音符。文本输入框和对话框不触发音乐快捷键。

`[` 缩短时值，`]` 延长时值，↑/↓ 改八度，`.` 附点，Shift+数字临时使用一半时值且不改变默认设置。最短十六分，拒绝再缩短。满拍仅在小节末尾推进到下一小节，满拍小节的中间插入明确提示，不自动转移音符。鼠标数字输入与键盘共用同一条插入操作。

[一分钟用户手册](../用户手册.md) 与界面“一分钟上手”说明一致。

**谱面内歌词编辑与手动排版**

歌词输入框直接覆盖在谱面文字位置，使用 SVG 坐标转换定位，缩放和滚动后仍对齐。点击已有歌词或虚线空格开始输入；Enter/Tab 提交并到下一音，中文组合输入期间不提交。离开输入或保存提交，Esc 取消。

拖动统一使用音符锚点，不再将同排移动写成自由像素偏移。默认移动源谱行的歌词后缀；目的地原有歌词及后续歌词按原顺序接在移动内容之后，跳过休止和无歌词的延音续音。预览和提交复用 `relocateLyricTail`，预览用副本渲染整张谱，使目标文字立即让位。空间不足时提示原因并保留原数据。

「只拖这个字」支持从同音多字文本中提取指定字符；源文本剩余字符保持在原音符，目的地歌词顺移。SVG 使用独立字符命中范围，选中的输入框也按鼠标实际按下位置判断字符。「当前音符 · 允许多个字」直接保存整段文本；连续输入分配仍作为另一种输入方式。歌词绑定音符，不限制每拍字数；旧文件 `offsetX` 可读取，被重新排列的歌词清除此偏移。原生格式继续为版本 2。
